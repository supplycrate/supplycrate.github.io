Addressables Build Bloat Explorer

Find assets duplicated across your Addressables bundles and see exactly which scene, prefab and material pulled each copy into your build.

Why is my Addressables build so big?

With Build Layout reports enabled, Addressables writes detailed build data — often tens of thousands of lines of JSON. Build Bloat Explorer reads that report and turns it into answers.

Top findings in plain language

“Hero_Body_Albedo.png is packed into 4 bundles (~8 MB estimated duplicated data).” Click a finding to jump to it.

Duplicates across bundles

Every asset packed into more than one bundle, with per-copy size, number of copies and estimated duplicated data, worst first.

“Why is this included?”

The chain that pulled in every copy — Level_Forest → Hero.mat → Hero_Body_Albedo.png — plus every asset that references it directly. Every link is clickable.

Group-level view

Which Addressables groups hold duplicated content, their packing mode, and which groups they share duplicates with.

Load size per bundle

Each bundle plus everything it depends on — what loading one level really pulls in.

Local vs remote content

Bundle bytes on local and remote load paths, per bundle and in total, with a finding when local content depends on remote bundles.

Compare two builds

What grew, which bundles were added, which assets gained extra copies — and why.

Tables, Show in Project, CSV

Sortable, searchable bundle and asset tables built for thousands of assets, with CSV export for every table.

Quick start

  1. Import the package. Addressables 2.9.1 or newer is installed automatically if it is missing.
  2. Open Window › Addressables › Build Bloat Explorer. No report yet? Click Explore Sample Report to try every tab right away.
  3. Build Layout reports are off by default in Addressables. Click Enable Build Layout Reports in the empty state.
  4. Build your Addressables content (Window › Asset Management › Addressables › Groups → Build), then click Load Latest.

Requirements

  • Unity 6000.3 or newer
  • Addressables (com.unity.addressables) 2.9.1 or newer
  • Tested with Unity 6000.3.18f1, 6000.4.10f1 and 6000.6.2f1; Addressables 2.9.1 and 2.11.2; Windows 11. macOS and Linux are not tested yet.
  • Reads the Build Layout report from Library/com.unity.addressables/BuildReports/
  • Full C# source included; Editor assemblies only
